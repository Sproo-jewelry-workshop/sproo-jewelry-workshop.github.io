# Jewellery workshops · Valencia

Website for Anastasia's jewellery workshops in Valencia (Jewellery Lab, Wax Carving, Silver Clay).

- `index.html` — the whole site (Home, three workshop pages, FAQ, Book), switched by `#hash` routes.
- `img/` — photos.

Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

Note: some photos are placeholders taken from other makers; replace them with your own work before publishing.
